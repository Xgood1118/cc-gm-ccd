在现有 ccd 骨架上，把它做成一个首次接触时间准确、退化情形确定的连续碰撞检测器。保留 Sphere、Capsule、sweep_sphere、time_of_impact 的现有名字与签名，
只用 Python 标准库，不得引入第三方依赖，不得改动 data/queries.json。

## 需要完成

1. **首次接触**
   - 球对静态球、盒、胶囊三种目标的首次接触时间必须与解析解在容差内一致。
   - 无接触时返回明确的无解标记，不得用负时间或极大值冒充。

2. **退化**
   - 起点已重叠时返回 0 并给出重叠深度；平行运动不得误报；零位移必须有确定结论。
   - 结果时间必须限制在 [0, 给定步长] 内，不得出现负值。

3. **多目标**
   - 一次查询多个目标时结果按时间升序，同一时刻命中多个时顺序稳定可复现。
   - 批量查询与逐个查询结果必须一致。

4. **相切**
   - 恰好相切的情形必须有确定判定，不得因浮点误差在两次运行间摇摆。

5. **规模**
   - 1000 条查询、每条 3 个目标，全部求交必须在 3 秒内完成。
   - 查询数翻倍时耗时不得出现超线性跳变，报告里要给出两组实测耗时。

## 测试

- 覆盖：解析解比对、已重叠返回 0、平行不误报、零位移、多目标排序稳定、相切判定、批量一致。
- `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m ccd.cli data/queries.json --out hits.json`，把查询数、命中数、最大时间误差、相切命中数贴进 README。
